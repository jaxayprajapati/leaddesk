# 60-second demo video: script and shot list

Record the screen with **Windows + Alt + R** (Xbox Game Bar), OBS, or Loom, at 1280×800 or larger. Speak over it, or add the lines as captions. Use demo data only (`backend/demo.db`, the Sunrise Realty agency); never a real agency's leads.

**Before recording**
1. Start the backend on a *copy* of the demo database with the AI on, and the dashboard (see "Run locally" in the README).
2. Turn on **Settings → Let the AI carry on the conversation**.
3. Put the website chat on a page (Connectors shows the one-line embed code). Any local HTML file with that line works.
4. Do one practice run, so the AI's answers are warm, then clear the browser's site data, so the recorded chat starts fresh.

| Time | Screen | Say (or caption) |
|---|---|---|
| 0–5 s | The agency's website, chat button bottom right | "Real estate leads come in all day and night. Most go cold before anyone replies." |
| 5–15 s | Open the chat, type name and email, ask: *"Looking to buy a 2BHK in Riverside, budget around 90 lakh."* | "LeadDesk answers every lead in seconds, from the agency's own listings." |
| 15–25 s | The reply suggests **Lake View 2BHK, ₹85 L** and offers a visit | "It found the matching property and the right price, and never invents one." |
| 25–35 s | *"Can I see it this Saturday?"* → the AI offers open times → *"10 AM is perfect."* → booked | "It checks the agent's diary and books the visit itself." |
| 35–42 s | *"Would the owner accept 78 lakh?"* → "I've handed this to the team" | "Negotiation needs a person, so it hands over, and tells the team why." |
| 42–52 s | Dashboard → **Leads → Needs you**: the lead, the booked visit, the details it captured, the full history | "The agent sees everything: what the lead wants, the booked visit, every message." |
| 52–60 s | Scroll to the README's **Measured accuracy** table | "Tested on 46 tricky enquiries in four languages: 92 out of 92 right." |

**Tips**
- Keep the mouse still while the AI is "typing"; cut the wait in editing (it takes about 5–10 s per reply).
- Zoom the recording to the chat window during the conversation, then back out for the dashboard.
- End on the LeadDesk name and your contact line.
